\section{Experiments}
\subsection{Base tracker performance results}
Firstly, the simplified correlation filter tracker was implemented and evaluated
using the Tracking toolkit-lite and the VOT 2014 dataset. We can see the 
results in Table~\ref{tab:corr_tracker_results}. Note that the used parameters here 
were:  $\sigma = 1.5$ and $\alpha = 0.3$, where $\sigma$ is the parameter
 of the Gaussian and $\alpha$ is the update speed parameter. Note that the 
 regularization parameter was set to 2000 (this value is used in all 
 evaluations in this assignment).
